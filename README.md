# ORBIS – Decision Intelligence Platform

A responsive single-page product website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` – page structure and content
- `style.css` – responsive orange, white and navy design
- `script.js` – mobile navigation, FAQ accordion and footer year
- `assets/orbis-hero-visual.jpg` – landscape hero visual

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a public GitHub repository (for example, `orbis-platform-site`).
2. Upload all files and the `assets` folder. Keep `index.html` in the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish the site and open the URL shown in the Pages section.

## Before publishing
- Confirm the demo/contact email address in `index.html`.
- Replace the generated hero visual with an approved Orbis product screenshot if one is available.
- Add the final Orbis/Ascentt logo and legal footer details if required.
